GLB: glTF Binary

GLB is the single-file, binary version of glTF. Geometry, materials and textures are packed into one file, which is why it is the standard for 3D on the web, in AR and on product pages. Typical use: web viewers, AR, e-commerce product pages, game engines.

glTF: GL Transmission Format

glTF stores the scene as readable JSON plus separate .bin and texture files. It holds the same data as GLB, just split into several files. Typical use: web 3D, editing material data by hand.

  • glTF to GLB
  • GLB to glTF

OBJ: Wavefront OBJ

OBJ is one of the oldest and most widely supported mesh formats. Geometry lives in the .obj file; colors and texture references live in a companion .mtl file. Typical use: exchanging meshes between almost any 3D program.

  • OBJ to GLB

STL: Stereolithography

STL describes a surface as a plain list of triangles, with no colors, materials or units. It is the default input for 3D printing slicers. Typical use: 3D printing and slicers.

  • STL to GLB
  • STEP to STL
  • IGES to STL
  • 3DM to STL

PLY: Polygon File Format

PLY is common output from 3D scanners and photogrammetry tools. It can store vertex colors alongside the geometry. Typical use: 3D scans and point clouds.

  • PLY to GLB
  • PLY to STL

OFF: Object File Format

OFF is a minimal text format listing vertices and faces, used mostly in geometry processing research. Typical use: geometry research and academic tools.

3DM: Rhino 3D Model

3DM is the native file of Rhinoceros 3D. It can hold exact NURBS surfaces as well as meshes, and is widely used in product, footwear and jewelry design. Typical use: Rhino, industrial and jewelry design.

  • 3DM to STL
  • 3DM to GLB
  • 3DM to OBJ
  • OBJ to 3DM
  • STL to 3DM

STEP: ISO 10303 STEP

STEP is the neutral exchange format for engineering CAD. It stores exact solids and surfaces, so SolidWorks, Fusion, CATIA, Creo and others can all read it. Typical use: exchanging solid models between CAD programs.

  • STEP to GLB
  • STEP to STL
  • STEP to OBJ

IGES: Initial Graphics Exchange Specification

IGES is the predecessor of STEP. It is still common in older engineering archives and in surface-heavy models. Typical use: older CAD data exchange.

  • IGES to STL
  • IGES to GLB

BREP: OpenCascade BREP

BREP is the native boundary-representation file of the OpenCascade geometry kernel used by FreeCAD and other open-source CAD tools. Typical use: OpenCascade-based CAD tools.

FCStd: FreeCAD Document

FCStd is the native project file of FreeCAD, the open-source parametric CAD program. Typical use: FreeCAD projects.

  • FCStd to STL

IFC: Industry Foundation Classes

IFC is the open standard for building information models (BIM), exported by Revit, ArchiCAD and most architecture software. Typical use: BIM and architecture (Revit, ArchiCAD).

  • IFC to GLB

FBX: Autodesk FBX

FBX is Autodesk’s interchange format for animation and games. It carries meshes, materials, hierarchy and animation between Maya, 3ds Max, Blender, Unity and Unreal. Typical use: Maya, 3ds Max, Unity, Unreal, animation.

  • FBX to GLB
  • FBX to OBJ
  • FBX to STL

DAE: COLLADA

DAE (COLLADA) is an XML-based scene format. SketchUp and many older tools export it. Typical use: SketchUp exports and older game pipelines.

  • DAE to GLB

3DS: 3D Studio

3DS is the legacy format of Autodesk 3D Studio. Many older model libraries are still distributed as .3ds. Typical use: legacy 3ds Max and 3D Studio models.

  • 3DS to GLB

3MF: 3D Manufacturing Format

3MF is the modern replacement for STL in 3D printing. It keeps colors, materials and units in a single zipped file. Typical use: modern 3D printing (Bambu, Prusa, Cura).

  • 3MF to STL
  • 3MF to GLB

AMF: Additive Manufacturing File

AMF is an XML format for additive manufacturing that, unlike STL, can store colors and materials. Typical use: additive manufacturing.

WRL: VRML

WRL (VRML) is an early web 3D format that is still exported by some CAD, scanning and scientific tools. Typical use: older web 3D and scientific visualisation.

  • WRL to STL
